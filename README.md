# 商品资料台

PyQt5 桌面工具，将商品 Excel 按款式汇总为品牌矩阵，同时保留全部商品明细、图片与备注。界面不显示总数统计、库存列或待核对入口。

## 启动

已打包的安装版位于 `dist/商品资料台-1.0.2-安装程序.exe`。双击后按照中文向导安装，可选择安装位置和桌面快捷方式。适用于 64 位 Windows 10 / 11，包含全部运行依赖，无需安装 Python。

Windows 双击 **start.bat**。本项目的运行环境放在 `.venv`，不修改系统 Python 配置。

首次安装或更换电脑时，需要 Python 3.10 及以上版本和联网下载依赖。在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
```

也可以手工创建环境后安装 `requirements.txt`，执行 `python main.py`。

## 使用

1. 点击“导入 Excel”，或把 `.xlsx` / `.xlsm` 文件拖入窗口。可选择多个文件。旧版 `.xls` 请先另存为 `.xlsx`。
2. 一款式一行；品牌列的 **√ 只表示存在该品牌商品**，所有品牌单元格默认使用 `#ff8b24`。颜色没有业务含义。“创建时间”取该款式所属商品最早的时间。
3. 主表双击备注，单选“已下架”“清仓”“无品牌”“批发专用”，也可以清空。双击商品名称可以为款式统一显示名称。
4. 鼠标停留在 √ 上，弹出可滚动的卡片，显示该款式所有商品编码和各自备注。当前品牌会突出显示。双击品牌格或点击右侧“查看 / 编辑商品明细”打开明细。
5. 在明细表格中双击商品名称、品牌、颜色、规格或商品备注可逐条修改。商品备注可选择状态，也可输入其它文字。
6. 按编码、名称、备注搜索，或使用品牌、款式备注筛选。筛选某品牌会保留该款式的完整明细。
7. 在“品牌规则”中配置名称、别名、顺序与颜色。新品牌优先补充规则，再重新解析当前数据；手工修正继续保留。
8. “导出 Excel”菜单可导出全部款式或当前筛选结果，输出“款式汇总”和“商品明细”两张表。

程序在前 20 行自动识别表头，不提供字段映射导入。需要“商品编码”“款式编码”“颜色及规格”或程序支持的常见别名；无法识别时请修改源表字段名称。一个文件有多个可识别的商品工作表时，可选择工作表。

## 数据规则

- 商品名称与品牌从“颜色及规格”解析，不依赖“商品简称”。明确无品牌时归为“原品牌”；测量规格后出现无法识别的尾部文字时标为“待确认”。
- “原品牌”是商品分类，“无品牌”是人工备注，两者独立。
- 支持常见颜色、长度等规则。无法可靠识别的复杂文本可以在明细中修正；原始“颜色及规格”始终保留。
- 源表的“商品状态”保留源值，不生成额外的上下架信息。
- 源数据中的空数值原样保留，不将其当作零。库存列和库存筛选不在界面显示。
- 相同商品编码、相同源数据只保留一条，并记录去重提示；相同编码出现不同数据时，本次导入失败并显示冲突位置，现有预览仍保留。
- 缺少商品编码或款式编码的记录保留并提示，避免静默丢失；缺少款式编码的商品不会互相合并。
- 库存与销量以导入文件的时点为准。本工具不自动连接店铺或库存系统。

## 保存与导出

手工修改、品牌规则、上次导入目录与显示设置保存在 `data/state.sqlite3`。重新导入同一商品编码或款式编码时保留手工修改，库存等源数据正常刷新。请备份此文件以保留备注。

安装版的设置与备注保存在 `%LOCALAPPDATA%\ProductDesk\data\state.sqlite3`，日志位于同目录的 `app.log`；默认导出到“文档\商品资料台”。升级或卸载程序不会删除这些数据。源码运行仍使用项目中的 `data` 目录。若需要把源码版备注迁移到安装版，请先关闭两个程序，再将项目的 `data/state.sqlite3` 复制到安装版数据目录，并保留原文件备份。

导出的“商品明细”只包含源表已有的字段，保留字段名称和顺序，不添加解析字段、来源信息、待核对信息、款式备注或“源·”重复列。导入多个不同结构的源表时，明细按首次出现的顺序合并已有字段。

手工修改的商品备注及其它信息仅写回源表中已有的对应字段；源表没有对应字段时，不新增列，修改仍保存在本地。款式备注和统一名称保存在本地及“款式汇总”中。源表已有的库存列仍按源数据导出，款式汇总默认不包含库存列。

Excel 导出保留图片、边框、品牌底色、表头筛选和冻结区域。主表备注具有下拉选择和随选择变化的颜色；品牌勾选格具有包含商品备注的 Excel 备注。Excel 中标签采用文字和单元格底色近似 GUI 的标签样式。

导出文件中的悬浮备注是**导出时的快照**。直接在 Excel 修改商品明细不会自动更新已有悬浮备注；需要重新导入“商品明细”工作表后再次导出。显示备注也取决于 Excel / WPS 的悬浮备注设置；完整内容始终保存在明细表中。

导出不会覆盖源文件。源文件里的文本及手工备注按普通文本导出，开头为 `=` 的内容不会作为公式执行。文件被 Excel / WPS 占用时，请关闭文件或换一个保存位置。

## 命令行

```powershell
.venv\Scripts\python.exe main.py "商品资料.xlsx"
.venv\Scripts\python.exe main.py "商品资料.xlsx" --export "outputs\商品资料_处理结果.xlsx"
.venv\Scripts\python.exe main.py "商品资料.xlsx" --export "outputs\原始解析.xlsx" --no-settings
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

程序异常日志位于 `data/app.log`。测试生成的临时文件不会修改导入样表。

## 重新打包

运行环境依赖位于 `requirements.txt`，打包依赖位于 `requirements-build.txt`。
安装 NSIS 3.12，或把官方便携 ZIP 解压到 `.build-tools/nsis-3.12` 后，在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

也可通过 `-NsisCompiler "路径\makensis.exe"` 指定编译器。构建脚本会生成 `dist/ProductDesk` 运行文件夹及一个中文安装 EXE；分发安装 EXE 即可。不要只复制运行文件夹中的 `ProductDesk.exe`，其依赖位于相邻的 `_internal` 目录。

图标源文件为 `assets/app-icon.png`，Windows 多尺寸图标为 `assets/app-icon.ico`，设计记录位于 `assets/icon-prompt.txt`。程序及安装器版本信息分别位于 `packaging/version-info.txt` 和 `packaging/installer.nsi`。
